# Project: Chess  
## Introduction  
Chess is a competitive two players strategic game which has a bunch of rules and pieces.  

## Implementation  
`implementation in ruby`  
You can play this game by following these steps:
1. You must have 'ruby' language installed on your system, including the compiler according to your OS  
2. Clone this github repo, goto directory and run the main file with ruby compiler  
```shell
git clone https://github.com/embeque/odin-rubyP-chess
cd odin-rubyP-chess
ruby main.rb
```
